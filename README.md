# ♟️ Chess Game

A simple and fun chess game that you can play directly in your browser. No download or installation needed.

## Features
- Play chess in your browser
- Clean and easy-to-use board
- Works on mobile and desktop

## How to Play
Open the link and start playing. Click a piece, then click the square where you want to move it.

- CSS
- JavaScript
